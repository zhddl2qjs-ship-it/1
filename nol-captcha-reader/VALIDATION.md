# 검증 결과

검증일: 2026-11-01 (한국 시간)

## 확인 완료

1. 업로드한 두 HTML을 파싱하여 모달·이미지·입력창·footer 버튼 위치를 확인했습니다. HTML의 실행 스크립트는 사용하지 않았습니다.
2. 실제 Chromium + Tesseract.js 5.1.1 WASM에서 `TTDUBN`, `UTDUUP`를 확인했습니다. 두 전처리 결과가 각 이미지에서 일치했습니다.
3. 동적 DOM 감지, native setter, input/change 이벤트, 버튼 활성화 대기, 중복 제출 방지, 모달 내부 버튼 제한, 이미지 교체 시 취소, 이미 입력한 값 보호, 인식 중 입력/입력 후 지우기 보호, 실행 중 끄기, 자동 클릭 끄기, 잘못된 OCR 결과 및 오류, 다시 시도, 숨겨진 모달, 비활성 버튼 보호를 포함하는 12개 시나리오가 통과했습니다.
4. 실제 React 18.3.1 controlled input, 실제 OCR 엔진, 실제 background/offscreen 메시지 핸들러를 함께 실행하는 로컬 구성요소 테스트가 통과했습니다. Chrome API만 테스트 대역으로 제공했습니다. 확장프로그램과 동일한 CSP를 적용했으며 외부 네트워크 요청이 없었습니다. `TTDUBN`, `UTDUUP`, 처음 대화의 `LUXQLS`가 각 한 번씩 입력·클릭되었고 관계없는 버튼은 클릭하지 않았습니다.
5. OCR worker 누락 시 오류와 재초기화 복구를 확인했습니다. JavaScript 구문 검사도 통과했습니다.

## 확인하지 못한 항목

테스트 환경의 Chromium 관리 정책 `ExtensionInstallBlocklist: ["*"]`가 확장프로그램 설치를 차단하므로 실제 설치 상태의 서비스 워커·offscreen 수명 주기 검증은 완료하지 못했습니다. 해당 정책은 변경하지 않았습니다.

실제 NOL 예매 서버에 접속하거나 인증을 제출하지 않았습니다. 저장 HTML에는 사이트 스크립트가 제거되어 서버 인증 성공 여부를 확인할 수 없습니다. 새 캡차에 대한 정확도는 검증한 세 이미지와 달라질 수 있습니다.
