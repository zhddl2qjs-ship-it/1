# Seat Watcher v2.2 — 맥북용 수정본

자동 갱신되는 좌석 화면에서 지정한 영역의 파란색·초록색·보라색 원형 좌석을 감지합니다. 테스트 모드로 위치를 확인하거나, 감지한 좌석을 한 번 클릭하고 멈춥니다. 예매 페이지 자체의 자동 갱신을 사용합니다.

**macOS 13 이상, Apple Silicon 및 Intel Mac용입니다.** 사용자가 알려주신 macOS 26.6.1을 고려해 ScreenCaptureKit으로 화면 캡처를 변경했습니다. 이 ZIP은 소스 배포본입니다. 첫 실행 때 Mac에서 앱을 빌드하므로 Apple 명령줄 도구가 필요합니다.

## 처음 실행하기

1. ZIP 전체를 압축 해제합니다. `Launch.command`만 다른 폴더로 옮기지 마세요.
2. 폴더의 **`Launch.command`를 우클릭 → 열기**로 실행합니다.
3. Apple 명령줄 도구 설치 안내가 나오면 설치를 마친 뒤 `Launch.command`를 다시 실행합니다. 최초 최적화 빌드는 수 분 걸릴 수 있으며 진행 시간이 표시됩니다.
4. macOS에서 실행을 차단하면 **시스템 설정 → 개인정보 보호 및 보안**에서 해당 실행 안내를 확인하고 직접 허용합니다. 보안 기능을 끄는 명령은 필요하지 않습니다.
5. **화면 및 시스템 오디오 기록**의 화면 캡처 권한을 허용합니다. 자동 클릭에는 **손쉬운 사용** 권한도 필요합니다. 안내가 계속되면 앱을 종료하고 다시 실행합니다.

`SeatWatcher.app`이 같은 폴더에 생성됩니다. 이후에는 앱을 직접 열어도 됩니다. 소스가 바뀐 경우 `Launch.command`를 실행하면 다시 빌드합니다. 재빌드 후 macOS가 권한을 다시 요청할 수 있습니다.

## 사용하기

먼저 **`테스트화면.html`을 브라우저에서 열어** 실제 예매 없이 색상·확대·위아래 좌표와 클릭을 확인할 수 있습니다. ‘5초 뒤 좌석 표시’ 또는 ‘같은 좌석 재등장 테스트’를 누른 다음 앱에서 감시를 시작하세요. 이 연습 화면은 네트워크를 사용하지 않습니다.

1. 주 모니터에서 브라우저의 좌석 화면을 열고, 창 위치·배율·스크롤 위치를 고정합니다.
2. 앱에서 **화면 촬영**을 누르고, 좌석만 포함하도록 감시 영역을 드래그합니다. 메뉴, 색상 범례, 버튼은 제외하고 좌석 원 주변에는 여백을 남깁니다. 영역 경계에 잘린 원은 감지하지 않습니다.
3. 원하는 좌석 색상을 선택합니다.
4. **테스트 모드**로 시작해 인식 위치와 색상을 확인합니다. 이 모드에서는 클릭하지 않습니다. 기본값은 **시작할 때 있는 좌석 제외**입니다. 이미 보이는 좌석으로 인식 테스트를 하려면 이 옵션을 끄세요. 빨간 표시는 감지 위치이며, 배경은 처음 촬영한 화면입니다.
5. 테스트가 맞으면 테스트 모드를 끄고 감시를 시작합니다. 한 번 클릭한 뒤 멈추므로 실제 선택 결과는 브라우저에서 확인합니다.
6. 중지하려면 메뉴 막대의 중지 항목 또는 **Escape**를 사용합니다. 클릭·스크롤·키 입력을 감지해도 감시가 중지됩니다. 손쉬운 사용 권한이 없는 테스트 모드에서 다른 앱의 키 입력을 받지 못할 때는 메뉴 막대에서 중지하세요.

**감시 중 창·탭·스크롤·줌·모니터 배치를 변경하면 다시 화면을 촬영하고 영역을 선택하세요.** 같은 브라우저의 창과 제목 등의 상태도 확인하지만, 모든 웹페이지 내부 변화를 식별할 수는 없습니다.

## 수정한 내용

- 보라색이 파란색 조건에 섞이던 색상 분류를 수정했습니다.
- 확대된 원형 좌석의 얇은 테두리를 인식하도록 원형 검사 방식을 보완했습니다.
- 시작 화면 하나와 계속 비교하던 방식을 개선해, 사라졌다가 다시 나타난 좌석의 상태를 추적합니다.
- 전체 화면을 매번 변환하는 대신 **감시 영역을 ScreenCaptureKit으로 연속 캡처**하고, 최적화된 탐지 엔진을 사용합니다.
- 순간적인 잡음을 줄이도록 연속 프레임 확인을 적용했습니다. 처리 시간 등의 관측값을 표시하며, 예약 성공 시간이나 고정 반응 시간을 보장하지 않습니다.
- 감시 중지·재시작 시 이전 결과가 섞이지 않도록 실행을 구분합니다.
- 화면 캡처 오류와 대상 브라우저 상태 변경을 표시하고 감시를 중단합니다.
- 테스트 모드, 한 번 클릭 후 중지, Escape 중지를 제공합니다.

## 오류가 나면

- **빌드 실패:** 같은 폴더의 `SeatWatcher_build.log`를 확인합니다. 오류 내용이 있어야 Mac에서의 호환 문제를 진단할 수 있습니다.
- **권한 허용 뒤에도 캡처 불가:** 앱을 완전히 종료한 뒤 다시 열고, 시스템 설정의 SeatWatcher 권한을 확인합니다.
- **감지 위치가 다름:** 주 모니터에서 테스트 모드로 다시 화면을 촬영하고 영역을 지정합니다. Retina 배율·위아래 위치를 먼저 확인합니다.
- **새로 나타난 좌석만 감지하는 모드:** 시작할 때 이미 있던 좌석은 제외합니다. 같은 좌석이 3회 이상 관측에서 사라지고 0.35초 이상 지난 뒤 재등장하면 다시 감지합니다. 새 후보도 2회 연속 확인합니다. 빠른 로딩·점멸과 실제 좌석 상태 변화는 화면 정보만으로 완벽하게 구분할 수 없습니다.

## 검증 범위

실제 배포되는 C 탐지 코드의 합성 이미지 검증과 셸·설정 파일 검사를 수행했습니다. **제작 환경이 Linux이므로 macOS 앱의 실제 빌드, 화면 기록 권한, Retina 클릭 좌표, 실제 반응 시간은 Mac에서 확인해야 합니다.** 합성 입력 검증은 실제 NOL 화면에서의 정확도나 예매 성공을 의미하지 않습니다.

개발자용 탐지 테스트는 폴더에서 `bash tests/run-tests.sh`로 실행합니다. 세부 빌드 정보는 `BUILD_NOTES.md`를 참고하세요.
