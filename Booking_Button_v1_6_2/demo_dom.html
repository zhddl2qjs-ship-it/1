버튼 DOM 상태 감지 연습

확장프로그램에서 활성 상태 변화(DOM)를 선택하고, 아래의 비활성 버튼을 지정하세요.
5초 뒤 버튼을 활성화합니다. 실제 예매나 네트워크 요청은 없습니다.

이 버튼을 확장프로그램의 ‘버튼 선택’으로 지정하세요.

버튼 상태대기 중 · disabled 있음
실제 클릭 이벤트0회
활성 상태 변경 → 첫 클릭 수신—

  1. 확장프로그램을 열고 감지 기준을 활성 상태 변화(DOM)로 선택합니다.
  2. 버튼 선택으로 위의 대기 버튼을 지정한 다음 감시 시작을 누릅니다.
  3. 이 페이지의 5초 타이머 시작을 누릅니다. 활성화 뒤 클릭 횟수가 1회가 되는지 확인합니다.
  4. 다른 동작을 연습할 때는 확장 감시를 중지하고, 초기화한 뒤 버튼을 다시 지정합니다.

파일로 연 페이지에서 확장 패널이 열리지 않으면 chrome://extensions → 해당 확장의 세부정보 → ‘파일 URL에 대한 액세스 허용’을 켜세요.
측정값은 이 연습 페이지에서 활성 상태를 바꾸는 시각부터 클릭 이벤트를 받는 시각까지입니다. 실제 예매 사이트의 서버 응답이나 예매 성공 시간을 측정한 값은 아닙니다.
