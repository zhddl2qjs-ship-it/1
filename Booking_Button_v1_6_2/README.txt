예매 버튼 한 번 클릭 v1.6.2

이번 버전은 기존 예매 버튼 확장에 ‘활성 상태 변화 (DOM)’ 모드를 추가한 수정본입니다.
맥북용 SeatWatcher나 SVG 좌석 감시 프로그램을 수정한 파일이 아닙니다.

1. 새 기본 모드: 활성 상태 변화 (DOM)

- 대기 중에는 disabled, aria-disabled, inert 등으로 클릭이 막혀 있는 예매 버튼을 선택합니다.
- 비활성 상태에서 감시를 시작한 뒤, 클릭 가능한 상태가 되면 색상 변화나 화면 캡처를 기다리지 않고 한 번 클릭합니다.
- 처음부터 활성인 버튼에서는 감시를 시작하지 않습니다. 색이나 글자로만 대기를 표현하는 버튼이면 ‘색상 변화 (기존 방식)’를 선택하세요.
- 버튼이 새 요소로 교체되어 클래스와 문구가 완전히 달라져도, 기억한 부모 영역과 위치·크기에서 대체 예매 버튼을 찾습니다. 기존 요소는 숨고 새 버튼이 나타나는 경우도 포함합니다.
- 같은 자리의 후보가 여러 개이거나 원래 버튼 영역이 사라지면 임의의 버튼을 누르지 않고 중지합니다.
- 색상이나 화면 캡처는 DOM 모드의 클릭 조건이 아닙니다. ‘화면 색으로만 판단’과 ‘캔버스·영상 버튼’ 옵션은 이 모드에서 비활성화됩니다.
- 버튼 상태 변경 알림은 즉시 확인합니다. 별도의 두 프레임 확인이나 고정 클릭 지연은 넣지 않았습니다.

2. 기존 색상 모드

감지 기준에서 ‘색상 변화 (기존 방식)’를 선택하면 v1.6.1의 색상·카운트다운 감시가 유지됩니다.
일반 버튼은 페이지의 색상을 직접 읽고, 이미지 등 색을 직접 읽지 못하는 경우에만 보조 화면 캡처를 사용합니다.
‘화면 색으로만 판단’과 ‘캔버스·영상 버튼’ 옵션도 색상 모드에서 사용할 수 있습니다.
시작할 때의 색을 기준으로 기억하므로 대기 상태에서 감시를 시작하세요.
DOM 모드와 색상 모드 중 한 가지가 동작하며 두 모드가 각각 클릭하지 않습니다.

3. 설치·교체 (맥북 Chrome)

1) ZIP 전체를 압축 해제하고 폴더를 보관합니다.
2) chrome://extensions 에서 기존 ‘예매 버튼 한 번 클릭’을 끕니다.
3) 개발자 모드를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’를 누릅니다.
4) manifest.json이 들어 있는 Booking_Button_v1_6_2 폴더를 선택합니다.
5) 예매 페이지를 새로고침해 이전에 주입된 감시 코드를 지웁니다.
6) 크롬 확장 아이콘을 눌러 패널을 열고 감지 기준을 선택합니다.
7) ‘버튼 선택’으로 아직 비활성인 대기 버튼을 지정하고 ‘감시 시작’을 누릅니다.

상태 감시는 탭을 앞에 보이게 두고 사용하세요. 패널이 버튼을 가리면 ⇄로 옮기세요.
Esc·중지·닫기로 감시를 중단할 수 있습니다. 최대 감시 시간은 1시간입니다.
‘예매 시간’ 입력은 보조 확인 주기를 조정하는 옵션이며, 지정 시각에 강제로 클릭하는 기능은 아닙니다.
프레임 안의 버튼은 기존 ‘프레임 안 패널 열기’와 필요한 경우 ‘프레임 접근 허용’을 사용합니다.

4. 새 DOM 연습 화면

- 같은 폴더의 demo_dom.html을 크롬에서 엽니다.
- 확장 세부정보에서 ‘파일 URL에 대한 액세스 허용’이 필요합니다.
- 확장 패널에서 기본 DOM 모드를 고르고 연습 페이지의 비활성 예매 버튼을 선택한 뒤 감시를 시작합니다.
- 연습 페이지의 ‘5초 타이머 시작’을 누릅니다.
- disabled 해제, 색상 미변경, 새 요소 교체, 비활성 재렌더링 후 활성화, 여러 속성 동시 변경을 시험할 수 있습니다.
- 색상 애니메이션을 켜도 DOM 모드는 애니메이션 완성을 기다리지 않습니다.
- 페이지는 실제 클릭 이벤트 수신 횟수와 DOM 상태 변경부터 수신까지의 시간을 표시합니다. 실제 놀티켓이나 서버 속도 측정값이 아닙니다.
- 다시 시험할 때는 확장 감시를 중지하고 연습 화면을 초기화한 뒤 대기 버튼을 다시 지정합니다.
- 기존 demo.html은 색상 모드 연습용으로 그대로 포함했습니다.

5. 결과의 의미와 확인 범위

‘1회 클릭’은 프로그램이 페이지에 클릭 동작을 보냈다는 뜻입니다. 실제 예매 진입이나 좌석 확보 성공은 페이지에서 확인해야 합니다.
페이지가 disabled 상태를 올바르게 제공해야 DOM 모드를 사용할 수 있습니다. 단순히 클래스 이름이나 색상만으로 대기를 표현하면 기존 색상 모드를 사용하세요.
실제 예매 사이트의 프로그램 클릭 처리, 확장 설치 권한·도구 모음 activeTab 부여, 다른 출처 프레임 접근은 사용 환경에서 확인해야 합니다.
로컬 자동 검사는 실제 watcher.js를 Chromium 페이지에 주입하여 진행했으며, 검사 내용은 검증결과.txt에 정리했습니다.
기존 대기 버튼이 보이는 채로 새 버튼이 겹치는 형태나 위치가 크게 바뀌는 교체는 자동 처리가 안 될 수 있습니다.
추가 권한은 요청하지 않으며 외부 서버나 별도 맥 앱은 필요하지 않습니다.
